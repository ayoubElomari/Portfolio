## The whole bridge to Rendr is one subprocess call

Shorts Engine never imports Rendr. It shells out to it, the same way it would
shell out to `ffmpeg`:

```python
command = ["rendr", "-v", rendr_version, "-o", video_path, "-j", json_path]
```

Every line of progress becomes exactly this, with nothing structured behind
it:

<TerminalLog
  lines={[
    { type: "progress", text: "Rendering video: ma_deuxieme_pote_part_1.mp4" },
    { type: "progress", text: "frame 412/1809" },
    { type: "progress", text: "frame 890/1809" },
    { type: "error", text: "codec warning: falling back to software decode" },
    { type: "progress", text: "frame 1809/1809" },
    { type: "info", text: "exit code 0" },
  ]}
/>

No percentage field, no severity level, nothing but text and an exit code.
That thin, honest seam is the entire contract between two of my own
projects: one produces `.rendr.json` files, the other one turns them into
video. Neither one knows anything about the other beyond that.

## One pipeline, two completely different shows

QuickLore and GesoLore ran through the exact same code. They don't look, read,
or sound like the same product.

<ChannelCompare />

<Facts variant="cards" bleed="wide">
  <Fact label="QuickLore" value="255 videos" note="English, r/stories, 82 production days, 3 posts a day" />
  <Fact label="GesoLore" value="161 videos" note="French, hyper-casual persona, 60 production days, 3 posts a day" />
  <Fact label="CutFun" value="1 video" note="A third format, tried once, cut fast" />
</Facts>

QuickLore's prompt asks for a clean, conversational rewrite: first person,
Reddit artifacts stripped out, a shock-hook opener that trades literal
accuracy for attention. GesoLore's prompt asks for something else entirely: a
"French TikTok ghostwriter" persona, written in hyper-casual slang, that
stays obsessively faithful to whatever its own hook just promised, with
every mid-story part ending on a cliffhanger built to pull a viewer into the
next one. Same pipeline, same render engine, same publish queue. Two
different writers living inside one prompt template.

The visual identity is just as split, and it's set entirely by a small style
file per channel: QuickLore in Oswald at a restrained size and Reddit orange,
GesoLore in the same font pushed larger, wider, heavier, and hot pink. Neither
channel required a line of new code. They required a different JSON.

## What actually ended it

Two separate things killed this, and they deserve to stay separate.

The channels got progressively shadow-banned, most likely flagged as
automated from very early on. Views cratered to almost nothing. No render
engine fixes that; it's a trust problem with the platform, not a bug in the
pipeline.

The other problem was mine to fix. Rendering one minute of video took about
20 seconds, and only by running eight to ten CPU threads at full throttle.
Every decoded frame got base64-encoded and stuffed directly into a JSON
payload passed into a browser tab. It worked. It was also exactly the kind of
architecture that stops working the moment you ask it to do more, which is
the entire reason [Rendr got rebuilt from the ground up](/project/rendr)
around a browser that decodes and discards a frame instead of hoarding it as
a giant base64 string.

Somewhere in the source, a function still starts with a comment its author
never deleted:

<TerminalLog
  lines={[
    { type: "info", text: '"""NOTE FROM DEVELOPPER: Uploading videos has' },
    { type: "info", text: 'been stopped for now."""' },
    { type: "progress", text: "return" },
  ]}
/>

That's what actually pausing your own project looks like. Not a clean
shutdown commit, a comment nobody went back to clean up, because there was
never a good moment to.

## Where it led

Shorts Engine never got to run against the fixed render engine. It didn't
need to, to be worth the three months: it proved a fully unattended
Reddit-to-YouTube pipeline could run at real volume, across three channels,
through real platform APIs, with nobody watching, for a Moroccan vacation and
then some. The bottleneck it hit is the same one that shaped everything
[Rendr](/project/rendr) became afterward.
